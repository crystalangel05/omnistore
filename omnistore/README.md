
# OmniStore 

A responsive online store homepage built with React and Vite.

## About the Project

OmniStore is a beginner-friendly e-commerce homepage project that demonstrates how React components work together to display product information.

## Features

- Store header with shopping cart icon
- Reusable product card components
- Product information passed using props
- Product lists rendered using map()
- Responsive product grid using CSS Grid
- Product prices displayed in INR

## Technologies Used

- React
- JavaScript
- Vite
- CSS

## Project Structure

- src/components/ - Reusable React components
- src/data/ - Product information
- src/App.jsx - Main application component
- src/index.css - Global styles

## How to Run the Project

1. Clone this repository.
2. Open the project folder in VS Code.
3. Install dependencies:

   npm install

4. Start the development server:

   npm run dev

5. Open the local URL shown in your terminal.

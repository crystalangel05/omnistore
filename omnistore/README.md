# OmniStore 🛍️

A responsive e-commerce website built with React and Vite.

## About the Project

OmniStore is a beginner-friendly e-commerce project developed as part of my React learning journey and frontend internship with SkillMe.

The project allows users to browse products, search for items, view product details, manage their shopping cart, and complete a demo checkout process.

## Features

### Week 3: Product Browsing and Shopping Cart

* Responsive product grid and reusable product cards.
* Real product data fetched from the DummyJSON API.
* Product search and filtering.
* Individual product detail pages.
* Navigation using React Router.
* Shopping cart with quantity controls and item removal.
* Loading and error states.
* Custom 404 page.
* Sage green and cream colour theme.
* Animated cart count feedback.

### Week 4: Cart Management and Checkout

* Global cart state management using React Context API.
* Shared cart functionality across components.
* Cart data saved in localStorage and restored after refreshing the page.
* Checkout page with customer information fields.
* Form validation for full name, phone number, address, and pincode.
* Order summary displaying products, quantities, subtotals, and total price.
* Demo order placement with a generated order number.
* Success confirmation after placing an order.
* Cart automatically cleared after a successful order.
* Responsive checkout layout with custom styling.

**Note:** Checkout is for demonstration purposes only. The application does not process real payments.

## How to Run the Project

1. Clone this repository:

   git clone https://github.com/crystalangel05/omnistore.git


2. Navigate to the project folder:

   ```bash
   cd omnistore
   ```

3. Install dependencies:

  
   npm install


4. Start the development server:

   
   npm run dev
   

5. Open the local URL displayed in your terminal.

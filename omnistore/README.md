# OmniStore 🛍️

A responsive e-commerce website built with React and Vite.

## About the Project

OmniStore is a beginner-friendly e-commerce project developed as part of my React learning journey and frontend internship with SkillMe.

## Features

* Responsive product grid and reusable product cards.
* Real product data fetched from the DummyJSON API.
* Product search and filtering.
* Individual product detail pages.
* Navigation using React Router.
* Shopping cart with quantity controls and item removal.
* Loading and error states.
* Custom 404 page.
* Sage green and cream colour theme.

## Technologies Used

* React
* JavaScript
* Vite
* React Router DOM
* CSS
* DummyJSON API

## How to Run the Project

1. Clone this repository.

2. Open the project folder in VS Code.

3. Install dependencies:

   npm install
   

4. Start the development server:
   
   npm run dev
   

5. Open the local URL shown in your terminal.
